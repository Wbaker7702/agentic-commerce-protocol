# Unreleased Changes

## Enterprise Program Features

Expand the ACP Enterprise Program with security and compliance support,
conformance certification, multi-region guidance, a Technical Account Manager
role, and a structured onboarding playbook.

### Changes

- **Security and Compliance**: Security advisories with advance disclosure,
  annual security review, and compliance mapping documents for PCI DSS, SOC 2,
  and GDPR
- **Conformance Certification**: Voluntary certification track with test
  harness access, a named Certification Engineer, versioned Certificate of
  Conformance, and a Certified Implementations registry
- **Multi-Region and High-Availability**: Reference architectures for
  multi-region deployments, regional data residency guidance, and load testing
  templates with suggested SLOs
- **Technical Account Manager (Premier)**: Dedicated TAM running monthly service
  reviews, maintaining a living integration runbook, and coordinating
  cross-team escalations
- **Onboarding Playbook**: Structured four-week onboarding path from kickoff to
  steady-state support
- **Feature Comparison Table**: Side-by-side Standard vs. Premier feature
  breakdown in the enterprise documentation

### Benefits

- **Production readiness**: Security advisories, compliance mapping, and
  multi-region guidance help organizations deploy ACP confidently at scale
- **Verifiable conformance**: Certification gives partners and auditors a
  concrete statement of protocol conformance
- **Deeper engagement**: The TAM role provides Premier customers with a stable
  technical contact across personnel changes and cross-team coordination
- **Faster time-to-value**: The onboarding playbook compresses the path from
  enrollment to steady-state support
